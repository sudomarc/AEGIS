# ForgeHacks Participant Perks

## Purpose

Track benefits that can reduce build cost during the ForgeHacks event. These perks are **not** judging requirements.

## Current official information

The current ForgeHacks site states that participant credits are distributed at the **start of the hackathon** so participants can use them during the build.

| Provider | Participant benefit | Planned AEGIS use |
|---|---|---|
| Featherless AI | $25 API credits; current page describes one month of unlimited access to 40,000+ open-source AI models | Primary model experimentation/provider |
| Momen | $100 credits | Optional rapid app/backend capabilities |
| Adaption | $500 credits | Optional automation/optimization |
| n8n | 1 month Cloud Pro | Optional workflows/automation |
| Kariaa | $40 credits | Optional |
| DevSwarm Pro | 1 month free | Optional AI coding assistance |
| Tin Computer | $299 credits per eligible team; current page says one month Growth plan and distribution after the event | Post-event/after distribution unless organizers confirm earlier access |

## Activation rule

At kickoff:
1. Verify the perk in the official ForgeHacks Discord/announcements.
2. Activate only what the chosen architecture actually needs.
3. Do not block the product on a sponsor tool that might be unavailable.
4. Keep a fallback provider or implementation path for critical capabilities.
